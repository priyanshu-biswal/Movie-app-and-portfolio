# Movies & Meet Priyanshu

A small React app featuring a searchable movie explorer and Priyanshu Biswal's interactive developer portfolio card.

## Features

- Search movies by title, genre, or release year.
- Add movies to and remove movies from favourites.
- View Priyanshu's profile photo, toggle the portfolio theme, like the profile, and send a greeting.
- Responsive layout styled with Tailwind CSS.

## Requirements

- Node.js 18 or later
- npm

## Run locally

Install dependencies:

```sh
npm install
```

Start the development server:

```sh
npm run dev
```

Open the local URL printed by Vite in your browser.

## Production build

Build the app:

```sh
npm run build
```

To preview the production build locally:

```sh
npm run preview
```
